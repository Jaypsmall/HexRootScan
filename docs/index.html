// HERRAMIENTAS Y CAPACIDADES

Cada módulo en acción. Sin rodeos.

Así funciona cada herramienta integrada dentro de la aplicación.

01 // NMAP INTEGRADO

🕵️‍♂️ Análisis avanzado de red

Realiza escaneos de puertos, detección de servicios activos, identificación de versiones y mapeo completo de hosts en tu red de forma nativa desde el móvil.

Escaneo de puertos Detección de servicios Descubrimiento de hosts Mapeo de red
02 // WHOIS & DIG

🌐 Reconocimiento de dominios y DNS

Consulta la información de registro y titularidad de cualquier dominio con Whois y analiza al instante todos sus registros DNS (A, AAAA, MX, NS, TXT) mediante Dig.

Consultas Whois Registros DNS Resolución de hosts
03 // AUDITORÍA WEB NIKTO

🔥 Escáner de vulnerabilidades web

Analiza servidores web objetivo para detectar configuraciones inseguras, cabeceras expuestas, software desactualizado y archivos o rutas peligrosas.

Escaneo web Fallos de configuración Archivos sensibles
04 // INTELIGENCIA OSINT

🛡️ Integración con Shodan

Conecta tu propia clave API de Shodan para buscar directamente dispositivos conectados a Internet, servicios expuestos y banners abiertos sin salir de la app.

Búsqueda de activos Puertos expuestos API Key propia
05 // PRIVILEGIOS SUPERUSUARIO

⚡ Listo para acceso Root (su)

Diseñada para aprovechar permisos de superusuario cuando los escaneos avanzados de red (como paquetes raw en Nmap) requieren ejecución con privilegios elevados.

Ejecución su Escaneos SYN / OS Máximo rendimiento
